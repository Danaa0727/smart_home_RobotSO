# RobotOS

Prototipo de sistema operativo simulado para un robot autónomo.
Proyecto Integrador de Sistemas Operativos.

- `index.html`: dashboard y terminal del sistema.
- `supabase/`: scripts SQL de la base de datos, usuarios y roles.
- `memoria-dana/`: módulo de memoria, archivos, logs y energía, en Python y JavaScript, con sus pruebas.
